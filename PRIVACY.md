# Privacy

Slow is a set of instruction files for humans to use with AI agents. It has no server, runs no code of its own, and makes no network calls.

- **What Slow collects:** nothing. It does not read, store, log, or send your data anywhere.
- **Web search:** the `cogsec` and `sift` skills may ask the agent to use its own built-in web search to check facts. Those searches are handled by the agent you are using, under that agent's privacy policy.
- **Your conversations:** everything you type is handled by the agent or app you run Slow in, such as Claude or ChatGPT, under that provider's privacy policy.

Questions: open an issue at https://github.com/sprice/slow/issues.
